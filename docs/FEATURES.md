## 2026-09-25 — Ручное указание класса напряжения ЛЭП оператором

Прямой запрос пользователя, по следам вопроса «почему такая малая площадь озеленения»: разбор показал, что на всех 3 демо-объектах допустимую зону съедает почти целиком ОДНО консервативное допущение — воздушные ЛЭП с неопределённым по чертежу классом напряжения получают максимально широкий отступ (55 м, тариф 1150 кВ). Пользователь: «человек имеет дополнительные материалы на руках и может самостоятельно определить класс объекта — сервис должен пересчитать параметры участка».

- `pipeline/constraints/lep_voltage_override.py` (новый модуль) — `apply_lep_voltage_override()`: заменяет отступ и цитату у ВСЕХ ЛЭП с неопределённым классом на участке, если оператор указал класс напряжения; без override поведение не меняется. Цитата явно проговаривает, что класс указан оператором вручную, не определён по чертежу.
- `pipeline/constraints/lep_zones.py::tier_options()` — типовые 8 тарифных порогов ПП РФ №160 для выбора (те же, что уже использовались для максимально консервативного допущения — новых категорий не придумано).
- CLI: `pipeline/run.py --lep-voltage-kv <кВ>` — тот же эффект для командной строки.
- Веб-UI: новый контрол в шапке «ЛЭП с неизв. напряжением (N), класс: [выпадающий список]» — появляется, только если на текущем объекте вообще есть такие ЛЭП (`GET /api/lep-voltage-tiers` отдаёт варианты, `lep_unknown_voltage_count` в ответе `/geometry` управляет видимостью). Выбор класса пересчитывает зону во всех местах: `/geometry` (отрисовка), `/generate` (автогенерация), `/review` (проверка ручного ввода).
- `pipeline/report/interpretation_report.py` — JSON-отчёт честно отражает, что произошло: `lep_unknown_voltage.operator_override_kv`/`applied_distance_m` рядом с прежним `fallback_distance_m` (что было бы по умолчанию), `known_simplifications` явно называет это человеческим решением, а не автоматическим определением по чертежу.
- **Проверено на реальном демо-объекте** («Песчаный переулок», 59 ЛЭП с неизвестным классом): без override допустимая зона под дерево — 219 м² (0.4% участка); с указанным классом «до 20 кВ» — зона выросла до покрытия практически всей площади участка, автогенерация разместила 279 деревьев вместо 4. Проверено вживую в браузере на изолированном порту (реальный сервер на 8000 не тронут) — скриншот подтвердил визуальный рост зоны.
- 10 новых тестов (`tests/test_lep_zones.py`, `tests/test_lep_voltage_override.py`, `tests/test_web_app.py`) — юнит-логика override, сквозной путь через `run_service_a` на синтетическом объекте, веб-эндпоинты. Полный `pytest tests/ -q` — 187/187.
