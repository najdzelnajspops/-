## ~~Выбор набора видов чек-боксами перед автогенерацией (веб-UI)~~ — реализовано 2026-09-24

Пользователь предложил при опробовании веб-UI (2026-09-18): вместо того чтобы автогенератор сам выбирал единственный вид дерева/кустарника для всего участка (тогдашнее поведение `pick_species()` — первый по алфавиту из рекомендованных), дать человеку выпадающий список с чек-боксами и поиском — выбрать ДОПУСТИМЫЙ НАБОР видов, а генерация распределяет посадки только среди выбранных.

**Решённые вопросы механизма распределения** (были открыты выше): по очереди (round-robin), в алфавитном порядке отфильтрованного набора — детерминированно, без seed, тот же принцип воспроизводимости, что и везде в проекте. Реализовано:
- `pipeline/placement/generator.py::pick_species_multi()` — фильтрует выбранные пользователем названия теми же двумя проверками, что и `pick_species()` (рекомендован+не инвазивен — перепроверяется заново, чек-бокс не обходит 369-ПП), плюс фитосанитарный конфликт (сноска [6]) с уже выбранными видами ДРУГОЙ жизненной формы (`avoid_conflict_with` расширен с одиночного вида до списка).
- `generate_placement(selected_species_names=...)` — новый необязательный параметр; `None` (по умолчанию) не меняет прежнее поведение ни на бит (проверено отдельным тестом). Задан — точки получают вид round-robin по `eligible_entries`.
- `PlacementResult.chosen_species_entries: list[...]` — новое поле (множественное число), `chosen_species_entry` (единственное) сохранён для обратной совместимости = первый элемент списка.
- Стоимость считается ПОФОРМА, по каждой точке отдельно (не `count × unit_cost`, как раньше) — у разных точек в многовидовом режиме разная стоимость.
- API: `POST /api/demo-objects/{id}/generate` принимает необязательное поле `selected_species: {"tree": [...], "shrub": [...]}`.
- Веб-UI: на вкладке «Автоматическая генерация» — чек-бокс-список с поиском для дерева и кустарника отдельно (`pipeline/web/static/app.js::setupSpeciesPicker()`), переиспользует существующий `/api/species`.
- 7 новых тестов (5 в `tests/test_placement_generator.py`, 2 в `tests/test_web_app.py`) + проверено вживую через Playwright (реальные клики по чек-боксам, поиск, генерация — несколько выбранных видов реально появляются на маркерах плана). См. `docs/CHECKLIST.md`, `docs/SESSION_LOG.md` за 2026-09-24.
