# Сервер (VPS): как устроен и как обновлять

Записано 2026-10-16 по итогам обновления сервера после замечаний экспертов финала. Пароли и ключи в документ не записываются: пароль пользователя `root` вводится вручную при подключении.

## Что это

- VDS (тариф VDS-KVM-SSD-Разгон-10.0: 2 ядра, 4 ГБ RAM, 60 ГБ SSD), Москва, активирован 2026-09-28. Панель управления — ISPmanager 6 lite.
- Адрес: `http://80.87.197.140:8000` (то же на порту 80 и по домену `najdzelnajspops.fvds.ru`). Swagger: `/docs`.
- Ubuntu, Docker. Код проекта — клон этого репозитория в `/opt/app` (`origin` = GitHub, ветка `main`).
- Сервис — контейнер `landscaping-service-web-1` (проект compose `landscaping-service`, сервис `web`, порт 8000, том `./data:/app/data`). Код копируется в образ при сборке, поэтому одного `git pull` недостаточно: образ нужно пересобрать.

## Как обновить

1. На своей машине: коммиты отправить в GitHub (`git push origin main`).
2. На сервере (`ssh root@80.87.197.140`):
```
cd /opt/app
git rev-parse --short HEAD > /root/app_before.txt
docker tag landscaping-service-web:latest landscaping-service-web:before-<дата>
git pull --ff-only
docker compose build web
docker compose up -d web
sleep 8 && docker compose ps
```
Пересборка около 2 минут, пока работает старая версия; при замене контейнера сервис недоступен примерно 10–20 секунд.
3. Проверка снаружи (без пароля): главная, `/docs`, три демо-объекта, ответы 422 на неверную категорию и на битый DXF. Не загружать на сервер валидные файлы: загруженный объект появляется в списке интерфейса до перезапуска контейнера.

## Откат

```
cd /opt/app
git checkout $(cat /root/app_before.txt)
docker tag landscaping-service-web:before-<дата> landscaping-service-web:latest
docker compose up -d web
```
