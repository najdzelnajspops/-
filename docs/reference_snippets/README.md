# Референсные фрагменты кода

Ранее подготовленные вспомогательные наработки (личные черновые модули автора, не публикуются и не являются частью данного проекта) — перенесены сюда один раз как отправная точка и дальше адаптируются на месте. Дальнейших обращений к исходному черновику не производится.

| Файл | Зачем взят | Что придётся переделать |
|---|---|---|
| `geocoding.yaml` | Готовая многопровайдерная схема геокодирования (несколько провайдеров с fallback) | Скорее всего не нужен основному пайплайну (координаты уже в исходной геооснове/кадастре); пригодится для опции «загрузить произвольный адрес» (Фаза 2) |
| `geo_context_collector.py` | Рабочий паттерн запроса к Overpass API (union-запрос, ротация зеркал при 429/504) | Набор тегов заточен под объекты инфраструктуры общего назначения — заменить на теги зелёных насаждений/дорог/зданий/линий электропередач |
| `nspd_mo_lookup_candidates.py` | Паттерн запроса к публичной кадастровой карте — получение геометрии/категории участка по адресу | Переориентировать запрос с «поиск по адресу» на «поиск по координатам/номеру участка», добавить извлечение слоя ЗОУИТ, если источник его отдаёт |
| `cadastral_registry_cache.py` | Паттерн локального кеша кадастровых записей (не бить внешний источник повторно за одни и те же данные) | Адаптировать схему кеша под структуру данных участка озеленения |
| `building_geo_cache.py` | Паттерн «геокодировали объект один раз → переиспользуем» | Аналогичный принцип для «участок один раз привязали к координатам → переиспользуем в истории посадок» |
| `location_enrichment_cache.py` | Паттерн многоэтапного кеша обогащения по координатам | Референс для Context Builder Agent |
| `md_to_pdf.py` + `report_template.md.j2` + `06_report_generator.py` | Готовая связка Jinja2 → Markdown → PDF | Заменить контент шаблона на отчёт интерпретации посадок (посадка → норма → пункт → вывод), см. [[REPORT_DESIGN]] |
| `FOOT_TRAFFIC_LIMIT_STRATEGY.md` | Образец описания многоэтапной стратегии сбора геоданных (локальный кеш → офлайн-слой → внешний источник только по необходимости) | Использовать как образец стиля для собственного документа по стратегии обогащения контекста участка |

**Примечание**: эти файлы — только черновая техническая основа для повторного использования паттернов (кеширование, работа с DXF/геоданными, генерация отчётов). Никакие внешние проекты не упоминаются в остальной документации этого репозитория.
