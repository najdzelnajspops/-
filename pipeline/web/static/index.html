Загрузить свой чертёж

Принимаются файлы .dwg и .dxf (можно несколько сразу — например, отдельные слои коммуникаций и границы участка). Обработка идёт синхронно: крупные объекты (десятки гектаров) могут занять несколько минут — не закрывайте вкладку.

Используемая нормативная база

Справочники обновляются вручную (заменой файла в data/reference/) — здесь видно, какая версия каждого сейчас реально используется.

Обновить цены из прайс-листа питомника

Загрузите прайс-лист (.xlsx/.xls/.docx/.pdf) — сервис попробует распознать категорию каждого растения (по каталогу ДПиООС, а где не получится — по ключевым словам в тексте) и предложит обновлённые цены. Ничего не применяется без вашего подтверждения ниже.
